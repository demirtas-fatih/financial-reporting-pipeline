# 📊 Automated Financial Reporting Pipeline

An end-to-end Python pipeline that **ingests** raw financial transaction data, **computes** KPIs, and automatically **generates** a formatted multi-sheet Excel report with charts — no manual work required.

> **Inspired by real automation work done at Siemens Healthineers**, where similar pipelines reduced manual reporting workload by ~30%.

## 🚀 What It Does

| Step | Description |
|------|-------------|
| **1. Ingest** | Reads raw CSV financial data (transactions per dept/category/month) |
| **2. Clean** | Filters unapproved entries, handles nulls, derives variance columns |
| **3. Aggregate** | Computes monthly & department-level KPIs (budget vs actual, variance %) |
| **4. Visualize** | Generates 3 charts (budget vs actual, variance %, dept spending) |
| **5. Report** | Outputs a fully formatted Excel file with 4 sheets |

## 📈 Report Structure (Excel Output)

### Sheet 1 — Executive Summary
- KPI banner: Total Budget, Actual, Variance, Over-Budget Departments
- Monthly Budget vs Actual chart
- Variance % by Month chart
- Department Spend chart

### Sheet 2 — Monthly Breakdown
- Month-by-month table: budget, actual, variance €, variance %, transactions
- Color-coded variance column (🔴 red = over, 🟢 green = under)

### Sheet 3 — Department Analysis
- Per-department breakdown with status indicators (✅ On Track / ⚠️ Over Budget)

### Sheet 4 — Raw Data
- Full filtered transaction log with auto-filter enabled

## ⚡ Quick Start

```bash
# 1. Clone & install
git clone https://github.com/demirtas-fatih/financial-reporting-pipeline.git
cd financial-reporting-pipeline
pip install -r requirements.txt

# 2. Generate sample data
python scripts/generate_data.py

# 3. Run the pipeline
python scripts/pipeline.py

# 4. Open the report
open output/Financial_Report_*.xlsx
```
